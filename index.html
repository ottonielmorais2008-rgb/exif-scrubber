EXIF Scrubber

Open a JPEG or PNG, review the hidden metadata (including GPS, camera, date and software tags), then download a clean copy. The file never leaves this tab: there is no server, and a strict Content Security Policy sets connect-src 'none' so the page cannot make network requests.

Inspect and strip metadata

What this tool does

  • Supports JPEG and PNG only. WebP is not supported.
  • Strips metadata as bytes: JPEG APP1 (EXIF and XMP), APP13 (IPTC/Photoshop), COM comments, and optionally APP2 ICC; PNG eXIf, tEXt, zTXt, iTXt, tIME, and optionally iCCP.
  • Pixel data is copied, not re-encoded, so JPEG/PNG quality is unchanged. There is no canvas fallback.
  • GPS values are shown as plain text and degrees only. They are never sent to an external map API.

Open source on GitHub. The file you choose is not uploaded.
